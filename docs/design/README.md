# Sebrus Mail Design Docs

This folder holds design source files and documentation for the Sebrus Mail app.

## Current scope

- **Mail portal** — the end-user mailbox UI.
- **Admin portal** — domain, account, and certificate management.

## Design files

- `MAIL_PORTAL.md` — end-user mailbox portal UX notes.
- `ADMIN_PORTAL.md` — admin portal UX notes.

VectorCraft source files (`.vectorcraft`) can be added here for wireframes, iconography, and marketing artwork.
